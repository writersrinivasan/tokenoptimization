# 🪙 Token Quest

An interactive, game-style Next.js app that teaches AI token optimization through industry case studies.

| World | Topic |
|---|---|
| 🔥 Dev Forge | Token habits while building apps with AI coding assistants |
| ⚓ API Harbor | Caching, batching, routing, RAG, and output control for API calls |
| 🚀 Agent Galaxy | Token-efficient agentic / multi-agent design, with an agent-loop simulator |
| 🕸️ Graphify Lab | Knowledge graphs so agents query a map instead of re-reading files |
| 📓 Obsidian Vault | Linked-notes "second brain" that stops the AI re-discovering context |
| 🕵️ Detective Arena | 33-question quiz with XP, ranks, and a review of missed answers |

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```

Companies in the case files are fictional and numbers are illustrative. Prices are an Oct 2026 snapshot — check the provider's pricing page.
